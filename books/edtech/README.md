## Reading notes and implementation boundary

The Global EdTech book recommends calm, low-clutter learning layouts,
mathematics rendered as dynamic visual ideas, and offline access. It also
warns that high-cost animation can stutter or drain batteries on low-end
phones and proposes falling back to static vector art. The public website now
uses a small, user-controlled Canvas visualization and keeps its existing
visual identity. It is not a copy of 3Blue1Brown's branded artwork, and it is
not the proposed offline learning application.

## Credential safety

The original Global EdTech PDF contains a credential-like value in an example
configuration. Do not copy or deploy it. If it is or was a real credential,
revoke and rotate it, and review the repository's sharing history. The supplied
PDF is preserved unchanged; this warning deliberately does not reproduce the
value.
