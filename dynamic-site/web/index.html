What the kernel guarantees

Exact result or refusal.

The existing rational core represents a value as a reduced numerator and positive denominator. For example, 0.1 + 0.2 is exactly 3/10—not a rounded display of a binary floating-point approximation. If an exact result cannot fit the kernel's supported range, it returns an error instead of silently rounding.
