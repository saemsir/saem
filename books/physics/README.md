# Physics references

This folder holds the supplied physics PDFs, including classical mechanics,
electromagnetism, thermodynamics, quantum mechanics, relativity, cosmology,
and field theory. Use the original filenames to locate a source; start from
the current work item and record the sections actually read in
[`DAILY_INTUITION.md`](../../DAILY_INTUITION.md).

For the Work-Time Engine, the Einstein and Feynman references support later
physics extensions; they are not substitutes for the algebra and linear
algebra checks required in the earlier slices.
