The model

A changing position has a shape.

Start at the origin with velocity u = 3 m/s. Constant acceleration bends the position-versus-time graph into a parabola.

x(t) = ut + ½at2 Here, u = 3 m/s

What changes when a becomes negative? Try it, then compare the velocity arrow with the curve's slope.

History format and calibration method

Each record represents one paper or exam session. Keep the exam series and paper language consistent, record its source, and include only topic labels a teacher has checked.

[
  {
    "board": "JEE Main",

    "language": "English",
    "source": "Official paper citation or URL",
    "reviewed": true,
    "topics": ["Mechanics", "Optics"]
  }
]

Each record's reviewed flag and citation are user supplied, not independently verified. The engine holds out whole years, fits a logistic calibration only on earlier out-of-fold years, and checks Brier score and calibration error on later held-out years. If evidence gates fail, it shows no probability. The corpus keyword candidates are not used as reviewed outcomes.
