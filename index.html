Built with clear boundaries

Many tools.
One source of truth.

The website is a static front end. C17 is the intended authority for bounded exact computation; research and teaching languages serve distinct roles around it.

  • C17 / QCOSKernel and exact arithmetic source exists; not a live web service.CORE
  • C++17EdTech engine source and tests exist separately.ENGINE
  • PythonOracle and verification tools; app integration is planned.TOOLS
  • R · Julia · Fortran · LispResearch or learning prototypes; not wired into the site.LAB
  • RustOpen Math archive is a reference, not a production dependency.REFERENCE
